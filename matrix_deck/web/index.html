The library is split across the two rails — first half left, second half right — so each column is half as long. A card plays on its rail's well; drag it onto either well or use the L/R badges to send it to the other side. Hover a card for a live thumbnail. Heart a card to favorite it. Click a group name to view it, or its + to add many cards at once. Save scene keeps both wells plus brightness and speed for one-click recall, with an optional daily time window. Press ? any time for keyboard shortcuts.

Not an official Framework product. MIT licensed — built for people who just bought a Framework 16 and want the LED wells to do something.
