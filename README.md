# LED Matrix

Desktop app for the two Framework Laptop 16 LED matrices.

## Install (Omarchy / Linux)

In a terminal:

```bash
cd ~/pixel-widgets
git pull
chmod +x install.sh
./install.sh
```

Then press the **Super** key (the key with the logo) and type **LED Matrix**. Click it. A window opens; the panels keep the looping animation you pick.

You can also run:

```bash
led-matrix
```

To remove it from the app menu:

```bash
cd ~/pixel-widgets
./uninstall.sh
```

## Using the app

- **Play here** on Left or Right, then click an animation card. It loops until you pick another.
- **Flappy Bird**: click the module or press space to flap.
- **Sketch**: click LEDs to draw, Shift+click to erase.
- Brightness is the slider above the cards.

## Animations

Flappy Bird, Fish tank, Digital rain, Campfire, Starfield, Plasma, Game of Life, Rainstorm, Snake, Pong, Equalizer, Warp tunnel, Scanner, Sparkler, Ripple, Breathe, Sketch.

If left and right are swapped: close the app, then `led-matrix --swap`.
