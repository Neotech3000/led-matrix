# Code of Conduct

Be kind. This project exists so people who just bought a Framework Laptop 16 can light up the LED wells without a fight.

## Expected

- Assume good intent, especially from first-time Linux users asking install questions.
- Critique code, not people.
- No harassment, hate speech, or sexualized language.
- Do not share private information (serial numbers, logs with hostnames you were not asked for, etc.).

## Not OK

- Personal attacks, trolling, or sustained derailing.
- Publishing others’ private data.
- Anything that would get you kicked out of a Framework community forum.

## Enforcement

Report problems to the maintainer at ee.adjahoe@gmail.com or by opening a GitHub issue if it can be public. Maintainers may warn, edit, or ban as needed.

This is a shortened, project-specific code of conduct inspired by the Contributor Covenant. By participating, you agree to it.
